# 99 앱 — 유저 저니 & 와이어프레임

> "하루 99분으로 인생을 운영한다"
> 중요한 것 딱 9개. 매일 같은 순서로. 가볍고 꾸준하게.

---

## 앱 개요

| 항목 | 내용 |
|------|------|
| 앱 이름 | 99 |
| 슬로건 | 하루 99분으로 인생을 운영한다 |
| 타이머 | 199분 (버퍼 포함), 실제 소요시간 기록 |
| 할 일 구조 | 뚝딱(3초) × 3 + 착착(3분) × 3 + 몰입(30분) × 3 = 9개 |
| 프로젝트 | 1개 활성 (일상습관), 평일/주말 루틴 분리 |
| 탭 구조 | 홈 / 알람 / 기록 / 설정 |

---

## 전체 유저 Journey

```
Phase 0 — 설치 & 온보딩
  ① 스플래시
  ② 컨셉 슬라이드 4장
       슬라이드1: 공감1 — 오늘 하루 끝났는데 할일 그대로
       슬라이드2: 공감2 — 며칠째 지워지지 않는 불편함
       슬라이드3: 아이덴티티 — 심플·시간·우선순위
       슬라이드4: 3-3-30 구조 + 99분9초 리빌 + 1[99]분 제한
  ③ 닉네임 입력
  ④ 모드 선택 (모닝 모드 / 일반 모드)
  ⑤ 알람 설정 (모닝 모드만)
  ⑥ 루틴 세팅 (템플릿 제공)
  → 오늘 탭 진입

Phase 1 — 매일 아침
  알람 해제 → 199분 자동 시작 (모닝 모드)
  또는 앱 열기 → 홈 대시보드 → "오늘의 99 시작하기" 탭

Phase 2 — 챌린지 실행
  뚝딱 → 즉시 완료
  착착 → 3분 타이머
  몰입 → 30분 타이머
  도중 종료 → 실제 소요시간 기록

Phase 3 — 완료 or 미완료
  9/9 완료 → 해방 화면
  시간초과 or 중간 종료 → 따뜻한 미완료 화면

Phase 4 — 기록 확인 (선택)
  달력 + 소요시간 차트 + 통계

Phase 5 — 루틴 관리 (가끔)
  설정 탭에서 편집 / 새 버전 저장
```

## 연동 API / 서비스 / 키값

### 1. Firebase — 핵심 백엔드

**Firebase 프로젝트 1개로 아래 서비스를 모두 관리**

#### 1-1. Firebase Authentication
**목적**: 유저 식별 (기기 변경 시 데이터 복원, 마케팅 분석 기반)

```
지원 방식:
  - 익명 로그인 (앱 첫 실행 시 자동)
  - Apple로 로그인 (익명 → 실계정 전환, 데이터 보존)

Xcode Capabilities:
  ✅ Sign in with Apple

Info.plist:
  없음 (GoogleService-Info.plist로 자동 연결)
```

**API 키 필요 여부**: ❌ (GoogleService-Info.plist에 포함)

---

#### 1-2. Cloud Firestore
**목적**: 유저 데이터 클라우드 저장 및 기기 간 동기화

**데이터 구조**:
```
users/{userId}
  ├─ nickname: string
  ├─ createdAt: timestamp
  │
  ├─ projects/{projectId}
  │    ├─ name: string          ("일상습관")
  │    ├─ version: number
  │    ├─ startDate: timestamp
  │    ├─ endDate: timestamp | null
  │    ├─ weekdayRoutine
  │    │    ├─ spark: [string, string, string]
  │    │    ├─ flow:  [string, string, string]
  │    │    └─ deep:  [string, string, string]
  │    └─ weekendRoutine
  │         ├─ spark: [string, string, string]
  │         ├─ flow:  [string, string, string]
  │         └─ deep:  [string, string, string]
  │
  └─ records/{YYYY-MM-DD}
       ├─ completedCount: number   (0~9)
       ├─ elapsedMinutes: number   (실제 소요시간)
       ├─ isSuccess: boolean       (9/9 완료 여부)
       └─ itemStatus: [bool × 9]  (각 항목 완료 여부)
```

**무료 한도**: 읽기 50,000회/일, 쓰기 20,000회/일, 저장 1GB
→ DAU 1,000명 기준 여유롭게 무료 티어 내 운영 가능

**API 키 필요 여부**: ❌ (GoogleService-Info.plist에 포함)

---

#### 1-3. Firebase Storage
**목적**: 동기부여 이미지 CDN 호스팅

```
구조:
  alarm-images/
    ├─ img_001.jpg
    ├─ img_002.jpg
    └─ ...

관리 방식:
  Firebase Console에서 직접 업로드
  → 구글 시트에 Storage URL 기록 (메타데이터 관리)
```

**무료 한도**: 저장 5GB, 다운로드 1GB/일
**API 키 필요 여부**: ❌ (GoogleService-Info.plist에 포함)

---

#### 1-4. Firebase Analytics
**목적**: 유저 행동 분석, 마케팅 최적화, 리텐션 파악

**추적 이벤트**:
```swift
// 온보딩
"onboarding_completed"
"alarm_set_during_onboarding"      // 알람 설정 전환율
"onboarding_alarm_skipped"         // 스킵 비율 → 알람 유도 최적화

// 챌린지
"challenge_started"
"challenge_completed"   { elapsed_minutes, streak }
"challenge_failed"      { completed_count, reason: "timeout"|"manual" }
"challenge_item_tapped" { type: "spark"|"flow"|"deep" }

// 알람
"alarm_dismissed"       // 챌린지 자동 시작
"alarm_snoozed"         { snooze_count }

// 루틴
"routine_edited"
"routine_version_created"

// 리텐션 지표
"streak_achieved"       { streak_days: 7|14|21|30 }
"app_opened_from_alarm" // 알람 → 앱 진입률
```

**마케팅에서 활용**:
```
온보딩 이탈 지점    → 슬라이드별 완료율 측정
알람 설정 전환율    → 온보딩 문구 A/B 테스트
챌린지 완료율       → 뚝딱/착착/몰입 중 어디서 막히는지
스트릭 이탈 시점   → 몇 일째 포기하는지 → 적시 푸시 알림
```

**API 키 필요 여부**: ❌ (GoogleService-Info.plist에 포함)

---

#### 1-5. Firebase Crashlytics
**목적**: 알람 크래시 즉시 감지 (알람 신뢰성이 앱 생명선)

```
자동 감지 항목:
  - 알람 미발동 크래시
  - 타이머 관련 충돌
  - Firestore 동기화 오류

알림 설정: Crashlytics → Slack/이메일 연동 권장
```

**API 키 필요 여부**: ❌ (GoogleService-Info.plist에 포함)

---

#### 1-6. Firebase Remote Config
**목적**: 앱 업데이트 없이 문구/기능 변경, A/B 테스트

```
활용 예시:
  온보딩 슬라이드 문구 A/B 테스트
  타이머 기본값 변경 (199분 → 다른 값 실험)
  신규 기능 단계적 롤아웃 (10% → 50% → 100%)
```

**API 키 필요 여부**: ❌ (GoogleService-Info.plist에 포함)

### 2. 구글 시트 — 알람 이미지 메타데이터 관리

**목적**: 이미지 순서, 글귀, 작가 관리 (이미지 파일은 Firebase Storage에 저장)

**시트 구조**:
| id | storage_path | quote | author |
|----|-------------|-------|--------|
| 1 | alarm-images/img_001.jpg | 작은 것을 매일 하는 사람이 결국 이깁니다 | 익명 |
| 2 | alarm-images/img_002.jpg | 오늘의 나는 어제의 내가 만들었다 | 익명 |

**연동 방식**:
```
CSV URL:
https://docs.google.com/spreadsheets/d/{SHEET_ID}/export?format=csv&gid=0

SHEET_ID = 구글 시트 URL의 /d/{여기}/edit 값
```

**앱 동작**:
